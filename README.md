# Sales Data Analysis Project

##  Problem Statement
This project focuses on analyzing sales data to understand business performance, identify trends, and generate meaningful insights.

## Dataset
The dataset contains sales records including order date, product category, sales, profit, and customer information.

## Objectives
 Analyze monthly sales trends  
 Identify top-selling products and categories  
 Evaluate profit distribution  
 Extract business insights from data  


## Tools & Technologies
Python  
  Pandas  
  Matplotlib  
  Jupyter Notebook / Google Colab  

## Data Processing Steps
Imported dataset using Pandas  
  Converted date column into datetime format  
Grouped data for monthly analysis  
  Cleaned and structured data for visualization  
##  Visualizations
 Monthly Sales Trend (Line Chart)  
 Top Selling Products (Bar Chart)  
Profit Analysis by Category (Bar Chart)  
## Key Insights
 Sales fluctuate across different months  
 Certain products generate highest revenue  
 Profit varies significantly across categories  
## Conclusion
This analysis helps in understanding business performance and supports data-driven decision making for improving sales strategy.
